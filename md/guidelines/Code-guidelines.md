## Copyright notice

Each file containing code **must** include a copyright notice at the top including **all** authors, in the following format: 

```java
/**
 *  /path/file
 *  
 *  Description of the functionality  of the file
 *  
 *  Copyright (C) YEAR name sirname <mailadress>
 */
```
